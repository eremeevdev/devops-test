# Тестовое задание для DevOps Инженера

## Развернуть приложение, которое состоит из трех частей:

1. **Frontend** — статические файлы (HTML, CSS, JS) в директории `/frontend`
2. **Backend** — Go приложение, готовый бинарник `backend-app-linux` в директории `/backend`
3. **Database** — MySQL база данных на отдельном сервере

## Что уже подготовлено на DB Server:

- MySQL установлена
- Создана база данных
- В базу залиты начальные данные
- Создан пользователь `go-app` с паролем `password`

## Что нужно сделать:

1. Развернуть Frontend на App Server (статические файлы)
2. Запустить Backend на DB Server. Backend принимает следующие параметры командной строки:
   - `--db-host` — адрес сервера MySQL (по умолчанию: `127.0.0.1`)
   - `--db-port` — порт MySQL (по умолчанию: `3306`)
   - `--db-user` — имя пользователя для подключения к БД
   - `--db-password` — пароль для подключения к БД
   - `--db-name` — имя базы данных (по умолчанию: `appdb`)
3. Убедиться, что при заходе на App Server:
   - Загружаются статические файлы (`/`, `/static/placeholder.svg`)
   - Frontend может сделать запрос на `/api/v1/text` и получить текст от Backend
   - Backend запрашивает информацию из MySQL и возвращает случайный текст в формате `{"text": "..."}`
